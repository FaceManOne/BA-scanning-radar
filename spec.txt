# Binance 监控系统 Spec

## 一、系统概览

**目标**：监控币安合约市场，对加密货币（Crypto）和传统金融（TradFi）两类资产，分别用不同阈值和门槛，推送即时警报和定期报告。

**数据源**：
- 行情：`https://fapi.binance.com/fapi/v1/ticker/price`（合约市场）
- 成交额：`https://fapi.binance.com/fapi/v1/ticker/24hr`（失败时回退到现货接口）
- 分类：`https://fapi.binance.com/fapi/v1/exchangeInfo`，`underlyingType != "COIN"` 的为 TradFi

**扫描频率**：每 20 秒一次（`extractInterval: 20s`）

**监控池**：
- Crypto：约 480 个 USDT 合约
- TradFi：约 209 个合约

---

## 二、档位定义（4 档）

每个分类有两个方向（涨/跌），每个方向有**四个档位**：**第0档、第1档、第2档、第3档**。

分类	第0档	第1档	第2档	第3档
Crypto 涨	2.5%	5%	7.5%	10%
Crypto 跌	-2.5%	-5%	-7.5%	-10%
TradFi 涨	1.5%	2.5%	3%	3.5%
TradFi 跌	-1.5%	-2.5%	-3%	-3.5%

**档位命名逻辑**：从 0 开始计数。

**档位间隔**：
- Crypto：2.5% / 2.5% / 2.5%（等距）
- TradFi：1% / 0.5% / 0.5%（越来越紧凑）

---

## 三、成交额门槛

| 分类 | 最低 24h 成交额 |
| :--- | :--- |
| Crypto | 30,000,000 USDT（30M） |
| TradFi | 9,000,000 USDT（9M） |

**低于门槛的币，任何报告都不出现。**

---

## 四、即时警报

### 4.1 触发条件

- 扫描时，如果某个币的 15 分钟滚动涨幅 **≥ 第0档**，且该币**未曾触发过该档位**，则推送一次即时警报。
- 档位只升不降：触发第0档后，除非涨到第1档，否则不再推。
- **最高可触发到第3档**。
- 每 15 分钟（整点 0/15/30/45）档位重置。

### 4.2 消息格式

```
🟢 BTC | 15m | 🌊3200.5M 📈+2.85% | 💲65000
```

| 元素 | 说明 |
| :--- | :--- |
| 🟢 / 🔴 | 涨 / 跌 |
| BTC | 币种（去掉 USDT 后缀） |
| 15m | 周期 |
| 🌊3200.5M | 24h 成交额 |
| 📈+2.85% / 📉-2.85% | 涨跌幅 |
| 💲65000 | 当前价格 |

**不加档位标记**，即使是第3档，格式也不变。

### 4.3 渠道

- **只发 Telegram**，不发邮件。

### 4.4 记录

每次即时警报触发时，向两个内存列表追加一条记录：

- `recent_alerts_15m`：用于15分钟汇总的追加区块
- `recent_alerts_1h`：用于1小时榜单的追加区块

记录内容：

```python
{
    "symbol": "SOLUSDT",
    "change": 0.054,       # 5.4%
    "price": 142.30,
    "level": 1,            # 第1档（从0开始）
    "direction": "up",     # "up" 或 "down"
}
```

## 五、15 分钟汇总报告

### 5.1 触发时机

- 每 15 分钟触发一次，对齐整点：`0 / 15 / 30 / 45` 分。
- 距离上次汇总超过 14 分钟才触发。

### 5.2 报告结构

```
📊 15分钟汇总报告 | 2026-09-29 12:15

📈 涨幅榜
  <上方榜单>
  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  <下方追加>

📉 跌幅榜
  <上方榜单>
  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  <下方追加>

🌊 市场潮汐
  Crypto Market Average: +0.04%
  🟢 279 / 🔴 223
  TradFi Market Average: -0.05%
  🟢 66 / 🔴 124
```

### 5.3 上方榜单（快照）

**逻辑**：这一刻，所有涨幅 ≥ **第0档**（Crypto 2.5% / TradFi 1.5%）的币。

- 按涨幅从高到低排序
- 最多列 20 个
- 成交额必须 ≥ 门槛

**格式**：

```
  GRASS | 56.8M  +2.67% | 💲0.1234
```

### 5.4 下方追加（回顾）

**逻辑**：过去 15 分钟内，**即时警报触发过**且**档位 ≥ 第1档**的币。

- **允许与上方重复**
- 同一币多次触发，只取**最高档位**的那次
- 用 35 个 `━` 分隔（缩进 2 格）
- 标记：涨用 🔥，跌用 ❄️
- 标记放在**行尾**，前面空两格

**格式**：

```
  US | 12.3M  +6.34% | 💲0.5678  🔥
```

### 5.5 市场潮汐

- **统计范围**：所有监控的币（不按成交额过滤）
- **统计方式**：全口径平均涨跌幅 + 涨跌家数
- **分两类**：Crypto 和 TradFi 分开
- **格式**：标题下缩进 2 格，数据行之间不空行

---

## 六、1 小时榜单

### 6.1 触发时机

- 每小时整点触发（`0` 分）。
- 距离上次超过 55 分钟才触发。

### 6.2 报告结构

```
⏰ 1小时榜单 | 2026-09-29 13:00

📈 1h 涨幅榜
  <上方榜单>
  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  <下方追加>

📉 1h 跌幅榜
  <上方榜单>
  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  <下方追加>

🌊 市场潮汐
  Crypto 1h Average: +0.15%
  🟢 310 / 🔴 387
  TradFi 1h Average: -0.08%
  🟢 8 / 🔴 22
```

### 6.3 上方榜单（快照）

**逻辑**：这一刻，过去 1 小时涨幅 ≥ **第3档**。

- Crypto 第3档：10%
- TradFi 第3档：3.5%
- 按涨幅从高到低排序
- 最多列 10 个
- 成交额必须 ≥ 门槛

**阈值来源**：从 `alertLevels` 里取 `up[3]`，不再单独定义。

### 6.4 下方追加（回顾）

**逻辑**：过去 1 小时内，**即时警报触发过**且**档位 ≥ 第2档**的币。

- **允许与上方重复**
- 同一币多次触发，只取**最高档位**的那次
- 用 35 个 `━` 分隔
- 标记：涨用 🔥🔥（2个），跌用 ❄️❄️（2个）
- 标记放在**行尾**，前面空两格

**为什么是第2档而不是第1档**：

- 15分钟汇总已经用了第1档，1小时榜单用第2档避免重复
- 1小时里能摸到第2档的，是真正的异动

### 6.5 数据不足

程序刚启动，1小时数据（180个点）不足时：

```
⏰ 1小时榜单 | 2026-09-29 13:00

📊 数据积累中...
```

### 6.6 市场潮汐

- 统计范围：所有监控的币
- 窗口：过去 1 小时
- 分 Crypto / TradFi 两类

## 七、记录的生命周期

| 列表 | 追加时机 | 清空时机 |
| :--- | :--- | :--- |
| `recent_alerts_15m` | 每次即时警报触发 | 每次15分钟汇总发完后 |
| `recent_alerts_1h` | 每次即时警报触发 | 每次1小时榜单发完后 |

---

## 八、邮件通知

### 8.1 只发两类

- 15分钟汇总
- 1小时榜单

**即时警报不发邮件。**

### 8.2 标题格式

```
15分钟汇总报告 | 2026-09-29 12:15
1小时榜单 | 2026-09-29 13:00
```

### 8.3 正文

和 Telegram 的消息正文完全一致（包含 emoji、`*` 加粗符号）。

### 8.4 收件人

支持多个收件人（`config.yml` 里用列表）。用 Bcc 隐藏收件人地址。

---

## 九、档位重置逻辑

| 事件 | 重置内容 |
| :--- | :--- |
| 每 15 分钟汇总后 | 所有币的 `push_level_up` / `push_level_down` 归 0 |
| 每 1 小时榜单后 | 清空 `recent_alerts_1h` |

## 十、价格与成交额的格式化

### 10.1 价格 `format_price`

| 价格范围 | 显示 |
| :--- | :--- |
| ≥ 1000 | 整数，如 `65000` |
| 1 ~ 1000 | 2 位小数，如 `142.30` |
| < 1 | 8 位小数，去掉末尾 0，如 `0.00001234` |

### 10.2 成交额 `format_volume`

| 成交额 | 显示 |
| :--- | :--- |
| ≥ 0.1M | 1 位小数 + M，如 `56.8M` |
| < 0.1M | `<0.1M` |

### 10.3 币种名 `strip_usdt`

去掉结尾的 `USDT`：

- `BTCUSDT` → `BTC`
- `MUSDT` → `M`
- `TSLAUSDT` → `TSLA`

---

## 十一、视觉规范

| 元素 | 规范 |
| :--- | :--- |
| 一级标题 | 顶格，如 `📊 15分钟汇总报告 \| ...` |
| 二级标题 | 顶格，如 `📈 涨幅榜` / `🌊 市场潮汐` |
| 榜单内容 | 缩进 2 格 |
| 市场潮汐内容 | 缩进 2 格 |
| 分隔线 | 缩进 2 格，28 个 `━` |
| 火焰/雪花 | 行尾，前面空 2 格 |
| 涨跌标记 | 即时警报用 🟢/🔴 + 📈/📉；报告里不加方向箭头 |

---

## 十二、档位与用途的完整映射

用途	使用的档位	标记
即时警报触发	≥ 第0档（最高可到第3档）	无
15分钟汇总 上方榜单	≥ 第0档	无
15分钟汇总 下方追加	≥ 第1档	🔥 / ❄️（1个）
1小时榜单 上方榜单	≥ 第2档	🔥🔥 / ❄️❄️（2个）
1小时榜单 下方追加	≥ 第3档	🔥🔥🔥 / ❄️❄️❄️（3个）

**整合原则**：所有阈值都来自 `alertLevels`，没有散落的硬编码值。`hourlyReportMinChange` 配置项已删除。

---

## 十三、系统目前不包含的功能（待办）

1. **多用户订阅**：目前只推给写死的个人 Chat ID，无法让其他人点 `/start` 后自动订阅
2. **峰值记录**：目前只记录“触发过第几档”，不记录“历史最高涨幅”

---

## 十四、配置项汇总

| 配置项 | 说明 |
| :--- | :--- |
| `apiUrl` | 币安合约 API 地址 |
| `chartIntervals` | 周期（目前只有 `15m`） |
| `outlierIntervals` | 15分钟触发阈值（`0.025`） |
| `alertLevels` | 4 档位配置（Crypto / TradFi 各 4 档） |
| `minQuoteVolume` | 成交额门槛（Crypto 30M / TradFi 9M） |
| `summaryEnabled` | 15分钟汇总开关 |
| `summaryMaxCoins` | 15分钟汇总最多列几个 |
| `hourlyReportEnabled` | 1小时榜单开关 |
| `hourlyReportMaxCoins` | 1小时榜单最多列几个 |
| `extractInterval` | 扫描间隔（`20s`） |
| `resetInterval` | 内存清理间隔（`12h`） |
| `dumpEnabled` | 是否监控跌 |
| `emailEnabled` | 邮件开关 |
| `emailReceiver` | 收件人列表 |
